# Smart Student Task & Assignment Planner

An Agile Sprint 1 MVP web application that helps students manage assignments, set priorities, track deadlines, highlight overdue tasks, and monitor completion progress.

## Features Implemented (Sprint 1 Backlog)
- **US1 - Add a new assignment:** Add task title, subject, due date, and priority.
- **US2 - View all assignments:** Clean tabular view of all scheduled coursework.
- **US3 - Update assignment status:** Switch tasks between Pending, In Progress, and Completed.
- **US4 - Set due dates and priorities:** Color-coded High, Medium, and Low priority badges.
- **US5 - Identify overdue assignments:** Automatically highlights uncompleted past-due assignments in red.
- **US6 - View progress summary:** Live counters for Total, Pending, In Progress, Completed, and Overdue tasks.
- **US7 - Project instructions:** Complete documentation for running and testing the app.

## How to Run the Application
1. Download `index.html` from this repository.
2. Double-click `index.html` to open it in any web browser (Safari, Chrome, Edge).
